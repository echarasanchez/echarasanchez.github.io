# Echar a Sánchez

Del 24 al 29 de noviembre de 2026 la ley electoral prohíbe difundir sondeos (artículo 69.7 de la LOREG) y, desde
el final de la campaña, propaganda electoral (artículo 53). Por eso esta versión del repositorio no lleva el
modelo, sus datos ni sus resultados: solo la web (`docs/`) con el aviso.
